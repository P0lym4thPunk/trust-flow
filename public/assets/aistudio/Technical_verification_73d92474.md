Technical verification

- Current Next.js and React compatibility.
- Current Stellar SDK package and Soroban RPC APIs.
- Current Stellar Wallets Kit setup and supported wallets.
- Current Rust toolchain and soroban-sdk version.
- Vercel runtime compatibility with required packages.
- Supabase server/client package recommendations.
- Current Gemini SDK and structured-output support.
Record the exact chosen versions in the repository and lockfile.
